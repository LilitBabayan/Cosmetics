# Lumora Cosmetics

A simple cosmetics storefront built with plain HTML, CSS, and JavaScript — no build tools required.

## Features

- Product grid with category filtering (Skincare, Makeup, Fragrance)
- Product detail modal
- Shopping cart drawer with quantity controls, persisted in `localStorage`

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server, e.g.:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
